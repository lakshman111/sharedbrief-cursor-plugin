# SharedBrief for Cursor and Grok Bot

SharedBrief turns content you choose to send into private drafts and shareable, unlisted briefs. This plugin connects to SharedBrief's hosted MCP server. It contains no credentials or application source code.

## Connect

Add the plugin from the Cursor Marketplace, then sign in to a free SharedBrief account through the OAuth prompt. The server URL is `https://www.sharedbrief.com/mcp`. No API key is needed.

## What it can do

- Create a private brief from content you select.
- List and retrieve your briefs.
- Publish a brief at an unlisted link that anyone with the link can open.
- Update a brief while keeping its link.
- Check approximate unique daily views.
- Unpublish or permanently delete a brief when you choose.

The production connector currently exposes eight tools. Interactive HTML documents and managed images are not enabled in production and are not included in this plugin's description.

Publishing is explicit. An unlisted link is not a private access control: anyone who has it can read the published brief. Unpublishing removes public access. Deleting a brief is permanent.
